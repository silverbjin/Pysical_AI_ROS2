# 12.7~12.8 구현·검증 계획

사용자의 초안을 실행 가능한 실습으로 통합한다. 기존 절의 관측·명령 의미를 보존하고 실제 보행 성능은 짧은 검증과 구분한다.

- [x] 12.6 남은 접촉 회귀·native/wheel·가이드·보고서·커밋 완료.
- [x] 12.7: 기존 기준 물성 복사본에서 에피소드별 질량·관성·접촉 마찰·모터 강도 랜덤화, 파생 상수 갱신. 누적 변조 금지. 실제 동작 지연·관측 지연 큐 초기화, 단위별 센서 노이즈, 명령/이력/목표와 센서 구분, 시드 재현. 외력은 body×6인 xfrc_applied로 적용·제거. 원래 qfrc_applied는 nv 벡터임을 교정. Dummy/Subproc 벤치마크, 실제 PPO와 한계 기록.
- [x] 12.8: ROS 없이 시험 가능한 관측·관절 매핑·행동 후처리 코어. canonical FR/FL/RR/RL 순서, wxyz↔xyzw, body/world 속도, 48차원 locomotion 규격, manifest/ZIP 검증. IMU 외에 선속도용 Odometry 입력 필수. 센서 누락·오래됨·시간 역행·비정상 추론을 감지하고 명령 중지/hold.
- [x] ROS 2 ament_python 패키지와 추론 노드·MuJoCo ROS bridge·Gazebo 어댑터/launch. 위치 타깃을 effort 명령으로 보내지 않는다. 실제 기존 Gazebo 개별 Float64 cmd_pos 인터페이스에 연결하고 관절 축·원점·한계를 교차 검증한다. 기존 FSM과 제어권 중복 금지. 기본은 모니터링(dry run), 실제 시뮬레이터 제어는 명시 launch 설정.
- [x] 실제 ROS 토픽 → 관측 → PPO → 명령 → 두 시뮬레이터의 관측 루프와 50Hz 시뮬레이션 시간 검증. 센서 지연·명령 timeout·NaN·관절 순서 변경 회귀. 가이드/수정 보고서/증거·독립 리뷰 후 로컬 커밋.

Ruling: 학습 모델이 없는 하드웨어 성능·장애물 회피 완성·고정 배수 가속은 주장하지 않는다. 실제 로봇 출력은 이 실습에서 실행하지 않는다. ROS 기본 통합은 12.3/12.4 locomotion 정책을 대상으로 하며 목표/LiDAR 정책은 필요한 추가 토픽 규격 없이 잘못 연결하지 않고 명확히 거부한다.
