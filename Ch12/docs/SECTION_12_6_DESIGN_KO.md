# 12.6절 LiDAR 장애물 회피 설계

사용자 초안을 기존 목표 이동·PPO 흐름에 통합한다. 기존 12.1~12.5 API는 유지한다. 성공 기준은 설치 가능한 패키지와 실제 센서·물리·학습·재생·종료 경로 검증이며 짧은 학습으로 회피 성능을 주장하지 않는다.

QuadrupedAvoidanceEnv는 목표 관측 48개에 16개(선택 32개) LiDAR 근접도를 붙인다. 기본 최대 범위는 5m다. 몸체 위 0.12m에서 몸체 자세를 따라 360도 광선을 발사한다. MuJoCo 3.3.7의 mj_ray에 geomid 출력 버퍼를 전달한다. geom group으로 로봇 전체·목표·바닥을 제외하고 장애물만 감지한다. 노이즈는 거리[m]에 표준편차 0.05m로 한 번 적용한 뒤 정규화한다. dropout은 최대 거리 반환으로 모사하며 기본 0이다. 동일 스텝의 관측 재조회는 난수를 소비하지 않는다. 보상은 깨끗한 거리로 계산한다.

전용 MJCF에 크기가 다른 10개 충돌 가능한 mocap 박스를 미리 만든다. 에피소드마다 위치를 재배치하므로 다양한 크기의 박스가 다른 위치에 나타난다. 동적 geom 크기 변경에 따른 충돌 가속 구조 갱신 문제를 피한다. 시작 위치와 박스 표면 사이 1m, 목표와 박스 표면 사이 도착 반경+0.55m, 박스 사이 0.15m를 확보한다. 목표 재샘플링도 같은 여유를 검사한다. bounded rejection sampling 실패는 오류로 보고한다. 전역 경로 존재는 보장하지 않는다.

모든 로봇 링크/발과 장애물의 접촉을 양쪽 geom 순서로 감지한다. 물리 하위 스텝의 접촉을 누적하고 충돌 시 종료·정확히 -100 보상, 목표 도착 보상은 차단한다. 비충돌 시 기존 목표 보상에 -weight×mean(max(0,threshold-distance)/threshold)×dt를 더한다. 기본 threshold 0.8m는 센서 원점 기준이며 실제 로봇 외곽의 안전 거리 보장은 아니다. body 프레임 스캔은 로봇이 기울면 함께 기울며 낮은 물체·낭떠러지를 탐지하지 못할 수 있다.

PPO에 avoidance 과제를 등록한다. 관측 차원과 LiDAR 의미를 manifest/ZIP schema로 검사하며 평가에서는 목표 도착 시 종료한다. 전용 데모는 기존 stand/random과 학습 정책 재생을 제공한다. 스캔 선·경로·장애물을 RGB/native에 표시하고 CSV에 충돌/최소 거리 진단을 남긴다.

테스트 → 실패 확인 → 구현 순으로 진행한다. 실제 거리·회전·자기 감지 제외·시드·노이즈 캐시·배치 안전·목표 갱신·접촉·종료·보상·체커·RGB·짧은 PPO·native 종료를 검증하고 기존 회귀·Gazebo·독립 리뷰를 완료한다. 가이드·보고서·증거와 함께 로컬 커밋한다.
