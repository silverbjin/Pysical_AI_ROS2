# 12.3절 State·Action·Reward 확장 계획

기준 커밋: 948718e. 기존 환경의 보상 계산을 override 가능한 메서드로 추출하고 새 `QuadrupedLocomotionEnv`를 추가한다. 기존 12.1/12.2 기본 인터페이스는 유지한다.

## 구현 규격

- 관측 48차원: 몸체 선속도 3 + 몸체 각속도 3 + 몸체 좌표계의 단위 중력 3 + 명령 3 + 명목 자세 대비 관절각 12 + 관절 속도 12 + 이전 적용 행동 12.
- 명령은 몸체 기준 vx/vy [m/s], 몸체 z축 회전속도 [rad/s]. 각 성분 [-3, 3]. 고정 명령·reset 명령 override·선택적 시드 기반 명령 범위 샘플링.
- 기본 위치 잔차 스케일 0.35 rad, 설정 가능 범위 (0, 1] rad. 실제 actuator 토크 한계는 유지한다.
- Gaussian: exp(-제곱오차/sigma), xy 추종과 회전 추종을 분리. 자세 기준은 중력 [0,0,-1].
- 기본 보상 가중치: 선속도 1, 회전 .5, 자세 .5, 실제 토크 제곱합 1e-4, 행동차 제곱합 .01, 비발 지면 접촉 링크 수 1. 각 비종료 항목은 dt를 곱하며 낙상은 일회 -10.
- 낙상 시 양의 추종·자세 항목을 0으로 하여 넘어지며 속도를 얻는 행동을 보상하지 않는다.
- 몸체 높이 <=0.2 m, 몸체 수직축 총 기울기 >=45°, 몸통 접촉은 terminated. 1,000스텝/20초는 truncated이며 보행 성공을 뜻하지 않는다.
- 보상 설정은 불변 dataclass와 JSON으로 제공한다. 보상 항목별 가중 기여·원시 항목·현재 명령·비발 접촉을 info 및 실행 요약에서 확인한다.
