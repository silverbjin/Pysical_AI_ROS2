# 12.2절 확장 계획

기준 커밋: b9a60c5. 기존 환경에 관측·제어 선택을 추가하는 확장 작업이다.

## 구현 규격

- 기본 `QuadrupedEnv`는 12.1절의 30차원·100 Hz·토크 제어를 유지한다.
- `QuadrupedTrainingEnv`와 호환 모듈 `quadruped_env.QuadrupedEnv`는 31차원 `[wxyz, 몸체 각속도, 관절 위치, 관절 속도]`, 물리 500 Hz/제어 50 Hz, 위치 제어가 기본이다.
- 위치 행동은 명목 관절각 + 0.35 rad × clip(action, -1, 1)이며 관절 범위를 넘지 않는다. MJCF position actuator에 PD와 토크 제한을 지정한다. 토크 모드도 선택할 수 있다.
- 두 MJCF는 공통 기구부를 include하여 모델 중복을 피한다. 모든 자산을 wheel에 포함하고 CWD와 무관하게 읽는다.
- reset 높이 0.5 m, 낙상 높이 0.2 m, 시드 노이즈, 기울기·몸통 접촉 종료 및 시간 제한을 지원한다.
- 보상은 12.1절의 항목별 보상을 재사용하되 에너지는 실제 actuator 출력으로 계산한다. 보상 고도화는 12.3절 범위로 남긴다.
- 수치 발산 시 MuJoCo의 자동 초기화를 성공 스텝으로 숨기지 않는다.
