# 13.6 교재용 게이트와 검증 비용 점검

작성: 2026-11-04. 최종 인수 완료 보고서가 아닌, 현재 오류의 원인과 교재 실행 범위에 대한 검토다.

## 결론과 실행 순서

과도한 조건 하나를 확인했다. **경로점 간격을 물리 계산 주기 2ms 이상으로 요구하는 조건을 제거한다.** 매 2ms마다 연속 곡선을 평가하는 제어기에서는 모든 경로점을 각각 한 번씩 명령할 필요가 없다. 기존 조건은 TOTG가 만든 짧은 마지막 구간 때문에 경로 전체를 불필요하게 늘려 120sim초 제한에 걸리게 했다. 120초나 속도·가속도 제한을 늘리는 방식으로 해결하지 않는다.

효율적인 순서는 저장된 원본 경로 재현 → 작은 수학/취소 시험 → 전체 부품 시험 한 번 → 설치·소스 동결 → 직전 실패 사례부터 실제 인수다. 같은 동결에서 통과한 사례를 이유 없이 다시 시작하지 않는다. 코드가 바뀌면 영향을 받는 사례를 새 소스로 확인하고 과거 결과는 별도로 보존한다. 각 가설마다 긴 통합 matrix를 시작했던 방식은 중단한다.

## 근거와 수정 범위

실패 UUID `49fb5608-8e1f-4b47-abff-400f7fdf2cf4`의 raw52.200598696초 경로에는 마지막0.598696ms 구간이 있다. 기존 전구간 시간 배율만으로 최소174초가 되어 거절됐다. 수정 후에는 실제 가속도 제한을 만족하는 배율2로104.401197392초에 유효하다. 다른 후보는98.639757194초이므로 여전히 그 후보를 선택한다. raw 시간이 짧다고 반드시 실행 시간이 짧은 것은 아니다.

실패 UUID `0ea3076c-44c4-4d59-bbaf-3a950a2f329a`는 pre-grasp 실행 후 Cartesian 접근에서 같은 정규화 오류로 중단했다. 당시에는 Cartesian 원본 궤적을 저장하지 않았으므로 정확한 마지막 구간 시간을 복원할 수 없다. 이후에는 원본 Cartesian 궤적도 저장한다. 이 실패가 이미 해결됐다고 선언하려면 새 실제 실행이 필요하다.

수정된 quintic 보간은 구간의 정규화 시간 u∈[0,1]에서 계수를 계산해 짧은 구간의 T⁻⁵ 계수 증가를 피한다. 전체 연속 곡선의 위치·속도·가속도를 기존 Bernstein 범위와 극값 검사로 검증하고 실제 명령은 기존2ms 주기로 평가한다. 시간은 양수로 증가해야 하고 끝점은 모두 보존한다. 별도 국소 padding이나 새 형상 오차 게이트는 추가하지 않는다. 취소 감속도 같은 검증기를 사용한다.

[ROS2 Control Jazzy의 궤적 보간 문서](https://control.ros.org/jazzy/doc/ros2_controllers/joint_trajectory_controller/doc/trajectory.html)는 위치·속도·가속도를 준 quintic의 가속도 연속성을 설명한다. 이 문서가 본 어댑터의 안전성을 보증하는 것은 아니며, 이번 간격 제한 제거의 근거는 실제 구현의 연속 범위 검사와 독립 보간 비교다.

저장 원본이 있는35개 파일의74개 성공 planning 출력은 엔진 없이 새 timing 검사에 모두 통과했다. 이는 당시 실제 실행·충돌·물리 파지가 모두 성공했다는 뜻이 아니다. 과거 Cartesian 원본 미저장 구간과 새 계획의 임의 경로까지 검증한 것도 아니다. 단위 시험은 독립 SciPy Hermite 보간과 짧은 끝 구간의 위치/도함수,2ms 샘플 간 변화량을 대조하며 과속·가속도 초과·시간 비증가는 계속 거절한다.

## 학생용 최소 흐름

의존성 준비·build·동결 확인은 설치 시 한 번 수행한다. 기본 실습은 동일 엔진 인계(hold), 작은 팔(arm_normal), MoveIt 계획/실행(moveit), 물리 pick을 순서대로 한 번씩 수행한다. 개별 명령과 결과 판독은 [실습 가이드](LAB_13_6_REUSE_GUIDE_KO.md)를 따른다. 별도 실행 없이 저장 관측으로 좌표 변환을 연습할 수 있다.

입력/관측 손실·중복 소유자·파지 중 취소·13.5 회귀는 개발자가 배포 전에 확인하며 학생에게는 선택 심화 과제로 제시한다. 실패한 원본은 보존하고, 제한을 낮춰 PASS로 바꾸거나 자동 재시도로 첫 실패를 감추지 않는다.
