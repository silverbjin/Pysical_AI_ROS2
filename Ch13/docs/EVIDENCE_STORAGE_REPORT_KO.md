## 앞으로의 기록 방식

정책은 [EVIDENCE_RETENTION_POLICY_KO.md](EVIDENCE_RETENTION_POLICY_KO.md)에 있다. 새13.5 native 실행기는 시작 전과 종료 후 보존을 자동 점검한다. 비대표 원본은 전체 관측 판정이 끝난 뒤 샘플·요약으로 바꾸고, 다음 실행에서도 대표와 pin을 제외한 자료가 누적되지 않게 한다. 비대표 원본은7일을 정리 기준으로 삼되 정상 완료 뒤에는 기간을 기다리지 않고 즉시 정리한다. 요약과 대표·pin 원본은 기간 만료로 삭제하지 않는다. 시작·종료 시점의 점검이므로 컴퓨터가 꺼진 동안7일째에 별도 서비스가 실행되는 방식은 아니다.

원시 관측2GiB·작업 증거8GiB·실행3,600초를 초과하면 기존 정상 정리 절차로 종료하고 해당 시험을 실패로 남긴다. 실행 중 약1초 간격의 감시이므로 하드 디스크 할당량 기능은 아니며, 한 감시 간격이나 대기 중인 쓰기만큼 일시 초과할 수 있다. 파생 파일 생성 후에도 다시 점검한다.

전체 프레임 판정이 필요한 인수 시험은 완전한 관측을 **임시** 사용한다. 샘플만 보고 짧은 접촉 손실·속도 초과가 없었다고 판정하지 않는다. 일반 장기 보존본과 요약 ZIP에는 모든 프레임을 반복 저장하지 않는다. 원래 안전·시간·소유권·종료 인수 기준은 유지한다.

비대표 전체 원본을 제거한 실험은 더 이상 전체 재생 자료가 아니다. 원래 `result.json`이나 과거 SHA를 고쳐 완전한 증거처럼 보이게 하지 않았으며, 제거 사실을 별도 원장에 기록했다. 해당 실험의 완전 재생이 필요하면 다시 실행해야 한다.
