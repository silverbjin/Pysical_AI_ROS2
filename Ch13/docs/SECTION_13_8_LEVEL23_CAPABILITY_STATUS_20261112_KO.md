# Level 2·3 실제 동작 범위와 목표 조정 검토

작성일: 2026-11-12 KST. 목적은 최종 PASS 여부만으로 개발 수준을 판단하지 않고 **실제로 어디까지 움직였는지** 확인하는 것이다. 저장된 실제 trial/BT/물리 판정과 보고서를 점검했다. 추가 튜닝·engine 실행·새 반복 평가는 하지 않았다. Level3의3회 한도 소진·중단도 유지한다.

**결론: Level2는 과거 버전에서 파지→운반→내려놓기까지 한 번 수행했다. Level3는 문 통과→관측→집기 위치 접근·팔 준비까지 확인됐으며 안전한 파지는 미검증이다.** 최신 코드가 과거 최대 동작을 안정적으로 재현한다고 입증되지는 않았다.

## 1. 동작 범위 요약

|동작|Level 2|Level 3|
|---|---|---|
|실제 보행·환경 통과|박스가 있는 경로와5도 경사 접촉을 확인|폭1.1m 교육용 문 통과를 확인|
|대상 관측·집기 위치 접근|알려진 원통의RGB-D 관측과 최종 정착 확인|식탁 아래 원통의RGB-D 관측과 최종 정착 확인|
|팔·그리퍼 준비|준비 action과 그리퍼 동작 확인|준비 action과 그리퍼 개방 확인. 준비 동작과 집기 접근 궤적은 구분|

|지지 후 내려놓기·후퇴·종료|v28의1사례에서 동일engine의 전체 동작 순서 완료|미검증|

대상은 알려진20g 원통이고 localization은 교육용 ground-truth다. 일반 콜라 인식·실제 주택·실기·새 전신 제어의 검증으로 확대하지 않는다.

## 2. 같은 버전의 고정 평가에서 어디까지 갔나

v28의 사전 고정10회 중 Level별5회만 비교했다. 이후 다른 버전의 유리한 사례를 이 분모에 섞지 않았다.

|완료 단계|Level 2, 5회 중|Level 3, 5회 중|
|---|---:|---:|
|최종 이동 완료|5|4|
|새 대상 관측/Find 완료|5|4|
|Pick 완료 및 물리 Pick PASS|3|0|
|귀환·Place·Finish 완료|1|0|
|기존 전체 성공 판정|0|0|

이는 **당시 v28의 단계별 도달 기록**이다. 현재 v52의 성공 확률이나 반복 강건성 보증이 아니다. Level3 나머지1회는 시작 준비 기한에 중단됐다. 당시 전체 성공0/10이라고 해도 모든 동작이 불가능했던 것은 아니다.

이번 점검의 저장 기록 목록에는 여러 버전의 Level2 27건·Level3 17건이 있었다. 이44건은 개발 조건이 달라 하나의 성공률로 합산하지 않았다. 기계 목록과 trial/BT hash는 `../evidence/section_13_8_policy/capability_audit_20261112.json`에 있다.

## 3. Level2의 최대 실제 동작과 최신 상태

최대 동작 사례는 **v28 / 621d134d-be0a-405c-af20-e5ac913940b7**이다. 실제 BT 기록에 navigate→find→pick→return→place→finish가 모두 완료돼 있다.

- 최소 lift101.245mm, hold2.22sim초, 양 finger 접촉100%로 Pick 물리 판정을 통과했다.
- 같은 engine에서 물체의CARRY 시작·끝 수평변위가약3.918m였다. 경로 누적 길이와는 구분한다. 운반 접촉비율100%였고 지정 수령 지지·손가락 개방·물체 분리·후퇴까지 진행했다.
- 종료까지259.912sim초/630.094wall초였다. 로봇 귀환 오차55.231mm이며, 별도로 물체 수령 위치·높이·지지·개방·놓은 뒤 유지 검사는true였다. 로봇 귀환 오차와 물체 놓기 오차는 같은 값이 아니다.
- 운반 중 세계 높이 하락23.360mm가 추가 물리 기준20mm를 넘어 transport 전체는FAIL이었다. 물체를 놓쳤다는 뜻과 동일하지 않다. 원래3cm·120초 목표도 미달했다.

이 한 사례의 시간·로봇 귀환 오차·기울기·CPU는 새 교육용600초·10cm·.15rad·85% 범위에 들어온다. 하지만 성공률80%를 입증하는 것도, 그대로 유지 중인 운반 높이20mm 검사를 통과한 것도 아니다. 과거 verdict를 성공으로 바꾸지 않았다. **동작 순서의 실행 가능성을 한 번 보여 준 사례**로 설명할 수 있다.

최근 계열에서는 v45/v48이 최종 접근과Find를 통과했다. v48 / 4f4d4ce4-0d83-40f8-a0e2-4584b6e3097b의 최종 이동 오차는11.311mm였지만 PRE_GRASP 중 관측 만료로 중단됐다. v50은 목표 위치에 가까워져도 방향과 함께 정렬하지 못했다. 마지막 v51 / 9a8a2b9c-3f35-4245-9cf7-e9e2aac876b5는 최종 이동 전에 관측·입력 수명 초과로 종료됐다.

따라서 **과거 최대 동작은 전체 순서 완료, 최근 계열에서 확인된 범위는 접근·관측까지이며 최신 연속 파지·운반·놓기 재현은 미입증**이다. 마지막v51은그접근도완료하지못했다. v28의경로·정책 설정과 이후 버전의 수명/제어 변경을 섞어 현재 성공이라고 말하지 않는다.

## 4. Level3의 최대 동작과 현재 경계

최근 실제 사례는 **v51 / e475ece0-9f70-4dae-8de9-491ee92c95fc**다. 실제 문 통과·식탁 아래 대상 관측·목표 부근 접근·정착·팔 준비 및 그리퍼 개방까지 진행했다. 최종 접근 목표는 대략(2.4,1.0), 관측 대상은대략(3.0,1.0)의바닥원통이다. BT의navigate 완료 시 목표 오차는39.437mm였다. 이 값은 최종 귀환 오차나 물체 위치 오차가 아니다.

이후 두 PRE_GRASP 후보가 MoveIt의 식탁 상판/link3 또는 식탁 다리/link7 경로 충돌로 거절됐다. 이 사례의집기접근팔궤적·파지·귀환·놓기는 미실행이다. 총48.844sim초/178.990wall초에 종료됐고12child 정상 회수·잔여 없음·lockfree를 확인했다.

과거 v36 / d0611273-5f74-47a8-b108-12d189dbd523에서는 팔의 PRE_GRASP 동작까지 실제 진행했으나 link3/world 금지 접촉으로 중단됐다. 이는 **팔이 움직인 기록**이지만 안전한 집기 기능의 성공 범위에는 넣을 수 없다. 최근 버전의 충돌 예상 경로를 실행 전에 거절하는 동작과 구분하며, 서로 같은 경로라고 주장하지 않는다.

충돌 해결을 위한 후속3회는 engine/팔명령 없는 저장 장면 진단이었다. 마지막은 시간화 중 서비스 응답 기한을 초과해 해결을 입증하지 못했다. 이 진단 결과로 실제 Level3 동작 범위가 확대된 것은 아니다.

현재 runtime 기준은 v52/402소스·94자산이다. v52는 교육용 평가 정책 변경이며 이후3회 진단 설정은 실습 코드에 반영하지 않았다. 따라서 최신 실제v51의 물리 동작 관찰과, v52로 새 실제 임무를 실행하지 않았다는 사실을 함께 기록한다.

## 5. 목표 조정과 다음 단계 제안

현재 근거에 맞는 교재 목표는 다음처럼 나눌 수 있다. **아래는 목표 변경 제안이며 이번 점검에서 실행 코드·합격 기준을 변경하지 않았다.**

|제공 수준|권장 목표|근거·주의|
|---|---|---|
|Level2 기본 실습|장애물·경사 환경에서 보행→관측 지점/집기 위치 접근→원통 관측→상태·안전 종료 판독|실제 도달 기록이 있다. 최신 실행에서도 항상 통과한다고 보증하지 않음|
|Level2 확장 시연|v28 고정 증거로 파지→운반→내려놓기 전체 동작 순서를 해설|실제1사례가 있지만 현재 코드의 안정 실행 실습과 구분. 새 환경 실행 검증 없이 학생 기본 성공 예제로 권장하지 않음|
|Level3 기본 실습|문 통과→식탁 아래 대상 관측·접근→팔 준비→충돌 계획 거절과 종료 판독|최근 실제 확인 범위와 일치. 계획 거절을 파지 성공으로 이름만 바꾸지 않음|
|향후 확장 과제|Level2 연속 임무 재현성과 Level3 충돌 없는 집기·운반·놓기|현재 필수 완료 범위에서 분리할 수 있다. 새 해결 작업은 이번3회 중단을 자동 해제하지 않음|

다음 단계는 추가 튜닝보다 **기본 실습과 확장 시연의 목표를 확정하고, 해당 버전·증거·실패 판독을 가이드에 명확히 연결하는 교재 패키지 정리**가 적합하다. 먼저 원래 전체 미션 목표가 무엇이었는지와 실제 도달 경계를 학생에게 공개하고, 최소 실습의 단계별 완료를 평가하도록 목표를 바꿀 수 있다. 이를 전체 파지·귀환·놓기의 인수 완료로 표현하지 않는다.
