# 13.5 교재용 게이트 개정 — edu_stop_v2

2026-11-02 사용자 지시: 전문서 자료 목적에 맞게 과도한 게이트를 조정하고 A 정착 원인을 제한 조사한다. 기존 원본/팔 목표 복사 실험의 FAIL은 그대로 보존한다. 이 문서는 후속 새 실행부터 적용한다. 기계 판별값은 [고정 JSON](../dependencies/section_13_5_edu_stop_v2.json)에 있다.

## 조정한 기준

이동 플랫폼의 미세 진동을 모든 순간의 3D 속도0에 가까워야 하는 조건으로 판별하면, 교재의 “작업 위치에 도착해 머문다”보다 강한 요구가 된다. 실제 작업 위치 유지와 팔 단계 인계에 필요한 양을 구분해 검사한다. 임계값은 교육용 설계 선택이며 인증값이 아니다.

| 항목 | 이전 R1 판별 | 새 교재용 판별과 이유 |
|---|---|---|
| 정착 시간 | 모든 순간 속도 조건을 연속1wall초 | 실제 새로운 관측으로1wall초 유지. 최소0.5sim초·25개 고유 표본도 필요해 pause로 시간만 채우지 못함 |
| base 선속도 | 매 표본 3D norm≤0.03m/s | 평면 속도 RMS≤0.05m/s + 창 안 xy변위≤0.03m. 상하 미세 진동을 평면 이동 실패와 구분 |
| base 회전 | 매 표본 3D norm≤0.05rad/s | yaw rate RMS≤0.20rad/s + yaw변화≤0.10rad. roll/pitch는 몸체 tilt≤0.35rad로 제한 |
| 팔 | 모든 순간 각 관절속도≤0.1rad/s | 관절별 속도 RMS≤0.20rad/s, 창 안 각 관절변화≤0.05rad, 실제 hold 목표오차≤0.10rad를 함께 검사 |
| 미세 한계 침투 | 별도 수치화 없음 | MuJoCo soft-limit 침투0.02rad 이내 허용. 명령 목표는 유효 관절범위 안이어야 하며 그 이상 침투는 실패 |
| 반복 | 인계안의 고정본 각 필수 시나리오1회 | 유지. 3회 반복·장시간 신뢰성은 확장. 수정 영향 검사는 하되 매번 전체 엔진 matrix를 반복하지 않음 |
| 원시 순간 peak | 단독 실패 원인 | 보존·진단. RMS·실제 위치/자세·팔 상태 조건을 함께 통과해야 함 |

정착 창은 sim시간 가중 RMS를 사용한다. wall초는 실제 대기 시간, 속도 단위는 engine sim초 기준이다. 창의 최초 자세를 기준으로 최대 xy/yaw/팔 관절 변위를 계산하며 yaw wrap을 처리한다. 명령은 창 전체0이어야 한다. 로봇/팔의 기하학적 수납 envelope와 IK 작업범위는 R2/R4에서 따로 검증한다. 여기의 팔 hold 통과를 READY_FOR_MANIPULATION 전체 승인으로 부르지 않는다.

실제 수치 불안정이나 큰 팔 진동은 이 완화로 숨기지 않는다. 이전6rad/s대 팔 진동은 RMS 조건으로도 조사 대상이다. A의 원본 PD 수치 문제가 확인되어 같은 연속시간 PD 법칙·게인·힘 cap을 native actuator로 표현하고 implicitfast로 적분하는 최소 보완을 별도 profile로 시험한다. 원본 그대로의 재현과 보완 profile의 결과를 분리한다.

## 유지하는 필수 조건

비유한 상태, 넘어짐(z<0.12m 또는 tilt>45도), 원래 모델 actuator 힘 cap 초과는 즉시 실패다. 게인·mass·접촉·물리dt·정책 가중치를 임의 조정하지 않는다. 원본 촬영 시각/최초 receipt·만료·단일 소유권·고장 latch·자동 재개 금지·실제 terminal/result·취소 ACK 구분·실측 정착과 프로세스 종료 구분은 유지한다.

Nav2 도착0.10m/0.10rad와 실제 정착1wall초를 유지한다. ROS2 freshness·watchdog 시간은 R2에서 의미와 운전 범위를 보고 사전 동결하며, 교재용 정착 기준을 근거로 만료 입력을 허용하지 않는다. 취소·장애물·막힌 경로·입력 손실·정상 종료를 최종 matrix에서 각1회 확인한다. 새 플랫폼에 무의미한 자체 crawl/QP 검사, Gazebo 동등 구현, 재학습, 전신 조작 최적화는 본문 필수에서 제외한다.

## 적용 범위

이번 실행은 ROS2 없는 R1 이동/정지/팔 hold 가능성의 제한 판별이다. U3–U7의 통합·수명·게시 전체 검증은 후속 과제다. 기준 조정만으로 과거 FAIL이나 아직 실행하지 않은 기능을 PASS로 바꾸지 않는다.
