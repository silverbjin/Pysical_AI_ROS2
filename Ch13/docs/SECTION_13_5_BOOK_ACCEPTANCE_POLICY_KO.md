# 전문서 예제 수준의 13.5 게이트 정책 — 2026-11-02

사용자의 최신 지시에 따라 교정 대기와 반복 실증 요구를 줄인다. 이 문서가 이전의
10wall초 교정 및 엔진별 3회 연속 필수 요구를 대체한다. 과거 실패는 그대로 보존한다.

## 완화한 조건

| 항목 | 책 예제의 조건 | 근거 |
|---|---|---|
| G1 교정 전체 대기 | 새 기본값 20wall초, 최초 요청 때 기한 고정 | 약6.5ROS초의 궤적과 실제1wall초 정착을 가변 실행 속도에서 10wall초 안에 강제하는 것은 시동 성능 목표다. |
| 최종 반복 실증 | 고정본으로 엔진별 crawl-cycle 1회와 crawl-reverse 1회 | 전체 이동·정지·역순 동작을 확인한다. 3회 연속은 선택적 강건성 검사다. 실패 뒤 수정하면 새 고정본에서 필수 사례를 다시 확인한다. |
| 개발 중 G1/C1 반복 | 원인 입증과 영향 검사 뒤 실행 | 작은 수정을 할 때마다 전체 로봇을 원인 탐색 도구로 쓰지 않는다. 새 실행의 현재 센서·기립·팔·정착 검사는 유지한다. |
| 포화 전 P값 | 새 명시 Gazebo 모델에서 추종 진단으로 기록 | 포화 전 `Kp*(q_ref-q)`는 실제 출력 토크가 아니다. 설치된 PD의 실제20/30Nm 제한은 유지하고 전체20축 예측 명령을 원래 한계로 제한한다. 일반 경로의 기존 검사는 유지한다. |

`calibration_wall_timeout_s`는 유한한 실수10~20초만 허용하며 bool·문자열·NaN·Inf는
거부한다. 해당 항목이 없는 기존 프로필은10초를 유지한다. runner와 명령 소유자는
같은 값을 사용한다. 전체 대기 연장은 센서 만료·기하/토크 위반·정착 실패의 즉시
중단이나 고장 상태를 연장하지 않는다. 신규11검사와 관련82검사, N빌드와 설치 감사로
확인했다. 신규11개는82개 안에 포함되며 합산하지 않는다.

## 유지한 조건

- 물리2ms, Controller Manager100Hz, 고수준50Hz, 기존 게인·native damper와 실제 hip20Nm/thigh·calf30Nm 제한.
- 실제 정착1wall초와 기존 몸체·관절 속도 기준.
- unload 벡터2mm/s·총10mm·6ROS초, 실제 선택 발 Fn<2N의100ms 유지.
- swing20mm/s·높이20mm·발 변위80mm, 기존 관절 범위와 미래 기하 검사.
- 관측200ms·완전 수신40ms·수치 전체10ms/32회 및 same-cycle 거래 전체10ms.
- 최신 TF 대체 금지, 단일 명령 소유권, 고장 latch, 자동 재시도 금지, 정상 종료와 서비스 복원.
- §13.4의 영상 해상도·촬영/추론 주기·수신 age·과거 TF·팔 갱신 주기.

실패267은 계산 시간 초과가 아닌 국소 infeasible이었다. 시간 한도나 토크 상한을
늘려 이 실패를 감추지 않는다. 상세 호스트 성능과 긴 시계 기록은 진단 근거로 보존하고
새로운 출판 필수 기준으로 확대하지 않는다.

## 힘 모델의 실제 기능 검사

미소 입력의 열별 상대 미분5% 검사에서 원본 로봇의7.9036% FAIL은 그대로다.
다음 조건은 별도 합성 입력을 실행하기 전에 고정했다.

| 조건 | 사전 기준 | 독립 합성 입력 결과 |
|---|---|---|
| 발별 힘벡터 예측 오차 | ≤0.1N, 기존2N release 기준의5% | 0.000304719N |
| 균형 목표 힘의 오차 비율 | ≤0.5, 목표 오차가 감소할 것 | 0.00239387 |
| 모든 지지력 | ≥2N | 최소33.25469N |

합성 입력은 이론 미분만으로 선택했으며 실제 측정 미분에 맞춰 매개변수를 조정하지
않았다. 한 정지 자세의 국소 기능 확인이다. 실제 접촉 해제와 전체 C1/G2의 증명은 아니다.

## 새 모델에서의 토크 의미

명시 `gazebo_discrete_equilibrium_v1` 경로는 전체 관성·감쇠·중력·접촉 기하를
반영한다. 전체20축의 예측 actuator 명령을 각 원래 한계로 제한하고 연속 물리 토크
추정 제약도 유지한다. 기본 경로는 기존 spring 모델과132행 검사를 유지한다.

포화 전 P값은 원본 그대로 별도 기록한다. 이를 실제 출력 토크로 표시하거나
클리핑한 값을 원본 P값으로 저장하지 않는다. 실제 출력은 기존 PD가 제한한다.
이 변경은 일시적인 PD 포화를 자동 실패로 보던 추가 요구를 새 경로에서 해제한다.
추종·비선형 과도 응답의 정확한 증명은 아니므로 실제 힘과 접촉 해제 검사를 유지한다.

현재 C1과 G2는 미완료다. 새 모델의 회귀 통과는 실제 실행 성공을 대신하지 않는다.
이 정책은 전문서 예제를 위한 설계 판단이며 공식 인증 기준으로 주장하지 않는다.
